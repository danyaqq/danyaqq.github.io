Questions fréquentes

J’ai acheté Premium, mais les catégories sont toujours verrouillées

Sur l’écran principal, touchez la roue dentée et choisissez « Restaurer les achats ». Vérifiez que vous êtes connecté à l’App Store avec l’identifiant Apple utilisé pour l’achat. C’est aussi ainsi que vous transférez Premium sur un nouvel appareil.

Premium est-il un abonnement ?

Non. Alias Premium est un achat unique : il débloque toutes les catégories payantes pour toujours, sans paiement récurrent.

Comment obtenir un remboursement ?

Les remboursements sont gérés par Apple. Envoyez une demande sur reportaproblem.apple.com.

Comment changer de langue ?

Dans les réglages de l’application, touchez « Langue » : les réglages iOS d’Alias s’ouvrent, et vous pouvez y choisir le français, l’anglais, le russe, l’allemand, l’espagnol, le japonais ou le coréen. Les mots du jeu changent en même temps que l’interface.

Où trouver les règles ?

Sur l’écran principal, touchez « Règles du jeu ».
